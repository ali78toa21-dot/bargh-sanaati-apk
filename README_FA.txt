برق صنعتی مهدیه — نسخه اندروید مبتنی بر نسخه وب
=================================================

این پروژه نسخه وب مستقل نرم‌افزار را داخل یک WebView اندرویدی اجرا می‌کند.
فایل HTML اصلی در app/src/main/assets/index.html قرار دارد.

امکانات:
- اجرای آفلاین رابط وب در اپ اندروید
- ذخیره داده‌ها در حافظه WebView همین برنامه
- انتخاب تصویر لوگو، مهر و امضا از حافظه گوشی
- پشتیبانی از چاپ / ذخیره PDF با پنجره چاپ اندروید
- حداقل نسخه اندروید: 6.0 (API 23)

ساخت APK بدون نصب نرم‌افزار روی گوشی:
1) این پوشه را در یک مخزن GitHub بارگذاری کنید.
2) در مخزن وارد زبانه Actions شوید.
3) گردش‌کار Build Android APK را انتخاب و Run workflow را بزنید.
4) پس از پایان موفق، در همان اجرای workflow بخش Artifacts را باز کنید.
5) فایل bargh-sanati-apk را دانلود و از حالت ZIP خارج کنید؛ فایل app-debug.apk داخل آن است.

نیازمندی ساخت ابری: حساب GitHub و فعال بودن GitHub Actions در مخزن.
این پروژه APK از پیش کامپایل‌شده نیست؛ workflow برای ساخت خودکار APK در فضای ابری آماده شده است.

نکته داده‌ها: داده‌ها داخل حافظه برنامه ذخیره می‌شوند. قبل از حذف برنامه یا پاک‌کردن داده‌های آن، از بخش تنظیمات و پشتیبان‌گیری، فایل پشتیبان بگیرید.
