چک یار - پروژه اندروید

این پروژه نسخه اندرویدی برنامه چک یار است و رابط اصلی را در WebView اجرا می‌کند.
امکانات شامل ثبت خودرو، پرونده سرویس و تعمیرات، بخش‌های تصویری و استیکرهای دسته‌بندی،
حذف خودرو، پشتیبان‌گیری و بازیابی اطلاعات است.

ساخت APK:
- با هر بار Push روی شاخه check-yar، گیت‌هاب اکشن به‌صورت خودکار APK دیباگ را می‌سازد.
- فایل APK از بخش Actions، اجرای Build Check Yar APK و قسمت Artifacts قابل دریافت است.
- برای ساخت دستی، پروژه را در Android Studio باز کرده و Build > Build APK(s) را انتخاب کنید.

نام برنامه روی گوشی: چک یار
شناسه بسته: ir.checkyar.khodro
داده‌ها در حافظه داخلی WebView ذخیره می‌شوند؛ برای جلوگیری از ازدست‌رفتن اطلاعات،
از گزینه پشتیبان‌گیری داخل برنامه استفاده کنید.
